# Image Assets

These files are the branded promotional graphics used by the frontend. Keep
the exact filenames below so the paths in `index.html` continue to work. PNG or
JPEG is fine; optimized WebP is also acceptable if the `src` paths are updated.

| Filename | Used for | Recommended size | Notes |
| --- | --- | --- | --- |
| `grooming-banner.png` | Home section banner | 1600 x 600 px | Wide landscape PawCare promotional graphic. |
| `bath-service.png` | Basic Bath & Dry card | 800 x 600 px | Service title graphic. |
| `full-groom-service.png` | Full Groom Package card | 800 x 600 px | Service title graphic. |
| `nail-trim-service.png` | Nail Trim & Ear Cleaning card | 800 x 600 px | Service title graphic. |

Keep individual files below 500 KB when possible so the page loads quickly. If
these graphics are replaced with pet photos in a later milestone, use clear,
well-lit sRGB images and do not include private client or pet information.
